# Music files

`city_ride_original.wav` is the game's original looping background track. It
starts automatically and is also available in the music player.

Commercial MP3 songs are not included in this public repository. To use the
optional playlist on your own computer, place MP3s you have permission to use
in this folder with these exact names:

- `jeena_jeena.mp3`
- `oh_oh_jane_jaana.mp3`
- `o_re_piya.mp3`

The `.gitignore` rule keeps MP3 files out of public commits. The game starts
the original track automatically. Press `M` to open the music player. Use
Up/Down to choose a track, Enter to play, Space to pause or resume, and
Left/Right to switch tracks.
