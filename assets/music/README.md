# Music files

MP3 songs are not included in this public repository. To use the optional
playlist on your own computer, place music files that you have permission
to use in this folder with these exact names:

- `jeena_jeena.mp3`
- `oh_oh_jane_jaana.mp3`
- `o_re_piya.mp3`

The `.gitignore` rule keeps MP3 files out of public commits. Press `M` in the
game to open the music player. Use Up/Down to choose a track, Enter to play,
Space to pause or resume, and Left/Right to switch tracks.
